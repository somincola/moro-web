# Moro security policy

Please report suspected vulnerabilities privately by emailing
[`support@somincola.com`](mailto:support@somincola.com?subject=Moro%20security%20report).

Include the Moro version and build number, iOS version, affected feature,
reproduction steps using test data, and the expected impact. Do not include a
real password or access token, and do not publish vulnerability details in a
GitHub issue before a fix is available.

The latest Moro version publicly distributed through the App Store is the
supported production release. Reports about newer test builds are also welcome
when their build number is included.

The full reporting policy and current supported version are published at
<https://moro.somincola.com/security>.
