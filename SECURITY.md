# Moro security policy

Please report suspected vulnerabilities privately by emailing
[`support@somincola.com`](mailto:support@somincola.com?subject=Moro%20security%20report).

Include the affected Moro feature, relevant account context, iOS version and
device model, reproduction steps using test data, and the expected impact. Do
not include a real password or access token, and do not publish vulnerability
details in a GitHub issue before a fix is available.

The full reporting policy and project security scope are published at
<https://moro.somincola.com/security>.
